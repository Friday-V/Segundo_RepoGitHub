# Segundo_RepoGitHub
El segundo ejemplo de repositorio GitHub

En la clase aprendimos a utilizar algunos comandos básicos de Git, como git add, git commit, git push y git pull, para guardar los cambios de nuestro proyecto, subirlos a GitHub y obtener cambios del repositorio

git add prepara los cambios, git commit los guarda y git push los sube a GitHub, mientras que git pull sirve para obtener los cambios que ya están en el repositorio. Creo que aprender esto es importante porque Git nos permite llevar un mejor control de nuestros proyectos y trabajar de manera más ordenada, especialmente cuando trabajamos en equipo
